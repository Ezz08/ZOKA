# ZOKA

Simple overview of use/purpose.

ZOKA is a photography team website designed to showcase creative photography work, highlight the team's services and benefits, present previous projects, and allow visitors to get in touch.

## Description

ZOKA is a modern photography portfolio website focused on presenting creative photography projects in a visually engaging way.

The website includes a hero section introducing the photography team, a section explaining why clients should choose ZOKA, an overview of the team and its work, project achievements, floral/event photography content, an image gallery showcasing completed photoshoots, and a final "Get Started With Us" section.

The project was built using HTML and CSS, with custom layouts, CSS animations, image galleries, hover effects, and smooth navigation between sections. The design uses the Poppins font and a custom color palette.

## Getting Started

### Dependencies

* A modern web browser such as Google Chrome, Microsoft Edge, or Firefox
* HTML5
* CSS3
* Internet connection for loading the Poppins font from Google Fonts

### Installing

* Download or clone the project files.
* Make sure the `index.html`, `css` folder, and `img` folder remain in their correct locations.
* Make sure all images referenced in the HTML are inside the `img` folder.

### Executing program

* Open the project folder.
* Open `index.html` with a web browser.

```text
Open index.html
```

* Use the navigation bar to move between the different sections of the website.
* Explore the photography projects and photoshoots.
* Use the "Get in Touch" buttons to access the contact links.

## Help

Make sure the project folder structure is preserved. The HTML file references images using paths such as `img/...`, so moving or renaming the image files may cause them not to appear.

The website is currently designed primarily for desktop screens. Responsive design for smaller screens is planned as a future improvement.
